# Land-Use and Land-Cover Change Analysis in Ga West Municipality, Ghana (2005–2025)

## Project Overview

This project examines land-use and land-cover changes in Ga West Municipality, Ghana, between 2005 and 2025 using satellite imagery and geospatial analysis.

## Methodology

* Acquisition and processing of Landsat and Sentinel-2 satellite imagery.
* Image classification using ENVI.
* Land-use and land-cover mapping.
* NDVI analysis.
* Accuracy assessment.
* Comparison of land-cover changes across the study period.

## Software and Technical Skills

* ENVI
* Remote sensing
* GIS and spatial analysis
* Satellite image processing
* Image classification
* Land-cover change detection
* NDVI analysis
